2. CORE API ROUTING (PORT 8000)
--------------------------------------------------------------------------------
- GET  /api/simulate         : Generates random collision telemetry for Monte Carlo.
- GET  /api/historical_events: Returns presets for BLITS and Canadarm2.
- POST /api/solve            : Runs the PINN network to output mass and velocity.
                               Accepts: dV (x,y,z), dW (x,y,z), sat_mass, sat_radius.
- POST /api/propagate        : Computes 30-day coordinates for debris clouds.

3. FORENSIC PHYSICS MODEL
--------------------------------------------------------------------------------
- Linear Momentum Transfer:
  m_debris * v_debris + M_sat * V_sat,0 = (m_debris + M_sat) * V_sat,post
  
- Profile Scaling Adjustment (Baseline 50.0 kg):
  m_actual = m_predicted * (M_sat,actual / 50.0)

- Torque / Attitude Spin:
  delta_omega = I_inverse * (r x J)  [where I = 2/5 * M_sat * R_sat^2]
